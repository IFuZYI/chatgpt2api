# 可比性报告

## 与 2.2.2 的兼容性

- 管理 API 路径与主要响应结构不变。
- `image_retention_days` 迁移到分钟级 `image_retention_minutes`；旧键继续派生返回。
- 账号对象新增 `last_relogin_*` 与 `disabled_*` 诊断字段。
- 「禁用」语义收紧为自动维护终态；这属于有意行为变更。
- 前端恢复入口扩展为接受「异常」与「禁用」。

## 与 Python 基线的偏离

- Go 版对 token 失效增加异常退避、抖动、密码重登与禁用终态。
- 未知状态采用调度白名单，避免外部状态值被当成正常账号。
- 这些偏离均为稳定性与风控增强，记录在 ADR-0014。
