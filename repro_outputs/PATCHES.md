# 2.2.3 补丁说明

## 账号生命周期

- 识别 password / MFA 两个阶段的 `account_deactivated`
- 成功刷新/重登清空历史失败计数与派生标记
- 未知错误码二次确认后禁用，防一次上游故障批量误杀
- 禁用号不参与任何自动维护，人工恢复为唯一解禁通道

## 代理与网络

- 密码重登、RT 续期使用账号绑定代理
- socks5/socks5h 使用 `x/net/proxy`，保持远程 DNS 与 HTTP/2
- 代理不可达时直接失败，不回退直连
- 所有持久化错误文本统一脱敏 URL 凭据

## 并发与状态写入

- 重登去重键从原始 token 改为解析后的账号身份
- 登录期间发生的人工禁用不会被成功回写撤销
- 在途图片任务只允许正常/限流之间切换状态
- 批量刷新不能降级或删除禁用号

## 清理

- 移除 7 个确认无引用的生产函数
- 删除未使用的 `web/bun.lock`，前端统一使用 npm lockfile
- CI 新增前端测试、类型检查、静态构建与 Docker smoke
