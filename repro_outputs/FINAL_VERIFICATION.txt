REVIEW OUTCOME (final whole-branch review)
------------------------------------------
Two Important findings and one Minor were raised and ALL fixed:
1. Refresh concurrency guard was keyed on the raw token string (alias-bypassable,
   same defect class already fixed for re-login). Now resolves to the account
   identity and returns that key for release; alias dedup tests added and
   verified to fail against the old implementation.
2. RecordInvalidTokenSeen persisted last_refresh_error unredacted — the 4th of
   4 persistence points. Now redacted; the redaction test was extended to cover
   it and verified to catch the regression.
3. Manual re-login on account_deactivated does disable (upstream-declared terminal
   fact); the contract comment said otherwise. Comment corrected and a boundary
   test added covering deactivated / invalid-password / need-TOTP.

Also fixed a flaky test introduced during this work: httptest.NewServer followed
by mutating srv.Config.ConnState is a data race (reproduced with
`-race -count=10`); switched to NewUnstartedServer → configure → Start.
